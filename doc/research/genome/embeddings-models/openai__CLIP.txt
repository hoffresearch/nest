openai/CLIP
category: embeddings-models   |   steal priority: HIGH

siblings: ./00-index.txt   |   map: ../../README.txt

what:        CLIP is a contrastively-trained dual-encoder (ViT/ResNet image tower + 12-layer Transformer text
             tower with byte-level BPE) that projects both modalities into one shared
             L2-normalized embedding space (embed_dim 512 for ViT-B/32) where cosine similarity,
             scaled by a learned temperature, is the native cross-modal metric.
innovation:  The unit-hypersphere embedding convention plus a single shared text/image space, which turns
             SIMD dot product into exact cosine and makes int8 quantization nearly lossless.
techniques:
  - L2 normalization to unit hypersphere so cosine(a,b) == dot(a,b) for unit vectors
  - Shared cross-modal embedding space: text and image projected to identical embed_dim (512),
    one index serves both
  - Byte-level BPE tokenizer with a 256-entry byte<->unicode bijection that skips
    whitespace/control bytes, vocab 49408, gzipped rank-ordered merges file
  - Regex pre-tokenization (contractions, unicode letter runs \p{L}+, single digits \p{N},
    symbol runs) before applying merges
  - Per-word BPE merge cache keyed on input token to avoid recomputation
  - Learned temperature logit_scale = exp(log(1/0.07)) (~100x) as a stored scalar that rescales
    raw cosine into calibrated logits
  - End-of-text token position used as the pooled text feature (deterministic single-vector
    reduction)
nest steals: nest-format: document/enforce L2-normalized embeddings in search_contract + store optional
             temperature scalar in provenance (additive, content_hash-safe). nest-runtime: adopt
             byte-level BPE (byte<->unicode bijection + frozen ranked merges section) in
             bm25::Bm25Index to fix the CJK/Thai tokenizer gap deterministically. Unlocks: exact
             cosine via raw SIMD dot product, near-lossless int8 compression, and a path toward
             shared text+image vectors for the 'fast image similarity' north-star.
compression: Directly central to extreme compression: L2-normalized unit vectors are the precondition that
             makes int8 (and even lower-bit) embedding quantization nearly lossless because
             every component lies in [-1,1] with a globally bounded scale, so a single symmetric
             quantization scale per vector or per file suffices -- maximizing nest's compression
             ratio while keeping the int8 tiny preset's 0.992 recall. It also lets cosine == dot
             product, so no extra magnitude bytes ever need storing.
perf:        Inference is GPU/PyTorch-heavy and out of scope for nest's runtime (nest never runs models). The
             transferable cheap part is purely the post-encoder convention: a single L2
             normalize (one pass) at build time, and a static byte-BPE lookup tokenizer with
             O(word_len^2) merges + per-word cache. Both are deterministic, allocation-light,
             and fit nest's offline mmap serving model. embed_dim 512 f32 = 2KB/vector raw, 512B
             at int8.
