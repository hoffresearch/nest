================================================================================================
genome :: hashing-crypto (index)
hashing, checksums, content addressing, authenticated encryption
================================================================================================

one file per project in this folder. open the one you need.

[HIGH     ] BLAKE3-team__BLAKE3.txt            A Merkle-tree hash built on a reduced-round
                                               (7-round) ChaCha-derived BLAKE2 compression
                                               function that splits input into fixed 1024-byte
                                               chunks, hashes them in parallel across SIMD lanes
                                               and threads, and combines chaining values
                                               pairwise into parent nodes, enabling parallelism,
                                               extendable XOF output, and verified streaming
                                               (Bao) where any byte range is verifiable against
                                               the single 256-bit root.
[HIGH     ] RustCrypto__hashes.txt             A pure-Rust collection of cryptographic hash
                                               crates (sha2, sha3, blake2, blake3 via
                                               traits-preview, ripemd, etc.) unified under the
                                               `digest` crate's
                                               `Update`/`FixedOutput`/`ExtendableOutput` traits,
                                               with the heavy backends doing runtime-dispatched
                                               hardware acceleration (x86 SHA-NI, AArch64 sha2
                                               extension, AVX2, NEON, WASM simd128) over a
                                               shared `block-buffer` block-accumulation
                                               abstraction.
[HIGH     ] skerkour__chacha20-blake3.txt      A no_std Rust committing AEAD that derives
                                               ChaCha20 + BLAKE3-keyed-MAC subkeys from a
                                               24-byte nonce via one BLAKE3 XOF call, encrypts
                                               with a from-scratch SIMD-dispatched ChaCha20, and
                                               authenticates Encrypt-then-MAC with a
                                               length-framed BLAKE3 keyed hash.
[MEDIUM   ] google__crc32c.txt                 A small C++ library computing CRC32C
                                               (Castagnoli/iSCSI polynomial 0x1EDC6F41) with a
                                               runtime-dispatched tiered backend: hardware
                                               SSE4.2 CRC32 intrinsics on x86_64, ARMv8 CRC32
                                               intrinsics on aarch64, and a portable
                                               slicing-by-4 (16 bytes/iteration) software
                                               fallback.
[MEDIUM   ] ogxd__gxhash.txt                   A non-cryptographic 32/64/128-bit hash that
                                               abuses the hardware AES round instruction (x86
                                               aesenc/AES-NI, aarch64 NEON vaes) as a wide
                                               bit-mixer over a 128-bit SIMD state, currently
                                               the fastest in its class at all input sizes
                                               (often >30 GB/s on large inputs).
