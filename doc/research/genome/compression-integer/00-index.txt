================================================================================================
genome :: compression-integer (index)
integer and posting-list compression (bitpacking, varint, elias-fano)
================================================================================================

one file per project in this folder. open the one you need.

[HIGH     ] powturbo__TurboPFor-Integer-Compression.txt A C library of the world's fastest
                                               integer-array codecs, anchored by TurboPFor (a
                                               SIMD/AVX2 patched-frame-of-reference scheme) that
                                               bitpacks fixed 128/256-int blocks with per-block
                                               exception lists and integrated FOR/delta/zigzag,
                                               plus directly-addressable random access into
                                               compressed data without full block decode.
[HIGH     ] lemire__FastPFor.txt               A C++11 library of vectorized integer-array
                                               codecs (SIMD-BP128, FastPFor/SIMD-FastPFor,
                                               StreamVByte, VByte, Simple9/16, varint-G8IU) that
                                               decode 4+ billion 32-bit ints/sec (~15 GB/s) by
                                               combining frame-based binary bit-packing with
                                               patched frame-of-reference exception handling
                                               over fixed blocks of 128 integers.
[HIGH     ] cruppstahl__libfor.txt             A tiny Apache-2.0 ANSI-C scalar codec for
                                               Frame-of-Reference (FOR) integer compression that
                                               bit-packs 32-bit integer residuals against a
                                               per-block minimum and supports random access,
                                               search, and append operating directly on the
                                               compressed bytes.
[HIGH     ] cruppstahl__libvbyte.txt           A C/C++ Apache-2.0 library that compresses
                                               32/64-bit integer arrays with variable-byte
                                               (VByte) coding, delta-encoding sorted sequences
                                               and using Daniel Lemire's MaskedVByte SSE/AVX
                                               kernel to decode billions of integers per second,
                                               while also exposing
                                               select/lower-bound-search/append primitives that
                                               operate over the compressed stream.
[HIGH     ] fast-pack__simdcomp.txt            A BSD-licensed C library that compresses blocks
                                               of 128 (or 256) 32-bit integers by SIMD
                                               "vertical" binary bit-packing - computing the
                                               minimal common bit-width b and packing values
                                               into b bits each - with an integrated
                                               delta+prefix-sum path for sorted lists, decoding
                                               at ~15 GB/s (0.3 cycles/int) on SSE4.1/AVX2.
[HIGH     ] ot__partitioned_elias_fano.txt     Reference C++ implementation (Ottaviano &
                                               Venturini, SIGIR 2014) of Partitioned Elias-Fano:
                                               it slices a monotone integer sequence into
                                               variable-length chunks chosen by a linear-time
                                               approximate dynamic program, encoding each chunk
                                               with the cheapest of plain Elias-Fano, an
                                               all-ones run, or a raw bitvector, giving
                                               near-optimal compression with constant-time
                                               random access and nextGEQ.
