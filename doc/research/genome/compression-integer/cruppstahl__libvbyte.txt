what:        A C/C++ Apache-2.0 library that compresses 32/64-bit integer arrays with variable-byte (VByte)
             coding, delta-encoding sorted sequences and using Daniel Lemire's MaskedVByte
             SSE/AVX kernel to decode billions of integers per second, while also exposing
             select/lower-bound-search/append primitives that operate over the compressed
             stream.
innovation:  Random-access and search directly on the compressed VByte stream without full decompression:
             vbyte_select returns the i-th value, vbyte_search_lower_bound does a binary search
             over delta-coded sorted data, and vbyte_append extends a stream in place - turning
             a compressed integer array into a queryable structure rather than an opaque blob
             you must inflate first.
techniques:
  - MaskedVByte SIMD decode (Lemire/Plaisance): uses per-byte high-bit continuation masks +
    SSE/AVX pshufb shuffle tables to unpack variable-length codes in vectorized batches
  - Delta + VByte for sorted/monotonic sequences (vbyte_compress_sorted32/64 take a `previous`
    seed so deltas, not absolute values, are stored)
  - Separate sorted vs unsorted codecs so unsorted data skips the delta transform
  - vbyte_select_sorted/unsorted: fetch index i by walking length-prefixed varints without
    materializing the array
  - vbyte_search_lower_bound_sorted: lower_bound over the delta stream returning position plus
    reconstructed actual value
  - vbyte_append_sorted/unsorted: append one integer to the tail of a compressed buffer in
    place, returns bytes written
  - vbyte_compressed_size_* sizing functions to pre-compute output buffer length before encoding
  - 32-bit and 64-bit width variants throughout, little-endian-only assumption
nest steals: Target nest-format, path crates/nest-format/src/sections/spans.rs plus a new encoding/varint
             codec under crates/nest-format/src/encoding/. Today chunks_original_spans stores
             byte_start/byte_end as fixed 16 raw LE bytes per chunk (spans.rs lines 21-24);
             within one source_uri these offsets are monotonically increasing, the exact
             delta+VByte sorted case. Re-encode each source's offsets as a delta-coded sorted
             varint stream to cut ~16 bytes/chunk toward ~2-4 bytes for close-packed chunks,
             shrinking a required non-embedding section that delta-varint beats structurally
             even after zstd. Make it purely additive: register a new reserved encoding id
             (4-255 free in v1) so old readers ignore it and NEST_FORMAT_VERSION never bumps;
             content_hash stays stable because it hashes DECODED canonical values, not the
             encoding. Implement in pure safe Rust (no C FFI) with a scalar varint loop first
             respecting the never-panic typed-error and small-core rules; MaskedVByte SSE/AVX is
             a later perf upgrade behind the existing nest-runtime SIMD dispatcher. The
             select/lower_bound primitives also map onto bm25 posting lists in
             crates/nest-runtime/src/bm25 if doc-id lists move to compressed deltas, enabling
             search over compressed postings without full inflate.
compression: Directly on-mission: delta+varint is the canonical way to compress sorted integer columns (byte
             spans, posting-list doc ids, chunk-id maps) below fixed-width or even
             zstd-on-raw-u64, deterministically and byte-reproducibly. It adds a structural
             integer codec to nest's toolbox (raw/zstd/f16/int8 today, none of which exploit
             monotonicity), advancing the compress-more-than-everyone north star for every
             integer-bearing section, and random-access select means compression does not cost
             queryability.
perf:        MaskedVByte decodes billions of ints/sec on AVX/AVX2 by branchlessly resolving continuation-bit
             masks with pshufb shuffle tables; scalar VByte is branchy (one branch per
             continuation byte) but tiny and cache-friendly. Monotonic 64-bit offsets whose
             deltas fit in ~12-14 bits drop from 8 bytes to 1-2 bytes each. Library is
             little-endian-only, matching nest's all-LE invariant. select/search walk the stream
             so they avoid allocating the decoded array entirely.
