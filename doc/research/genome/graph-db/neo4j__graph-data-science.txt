what:        A JVM graph-analytics library whose core asset is an immutable, in-memory Compressed-Sparse-Row
             (CSR) graph store that compresses each node's adjacency list with sort -> delta ->
             variable-length (VarLong) byte encoding, plus an optional block-based integer
             bit-packing strategy ("PackedAdjacencyList") tuned for branch-light, cache-local
             decompression during traversal.
innovation:  Lossless small-integer column compression via sort -> delta -> VarLong, plus block bit-packing
             at per-block minimum bit-width, decoded branch-free with cache locality on the hot
             path.
techniques:
  - sorted delta encoding
  - VarLong/LEB128 variable-length integers
  - CSR: offsets + degrees + paged compressed targets
  - block bit-packing at per-block minimum bit-width
  - tail strategies for partial blocks
  - HugeArray paging
nest steals: crates/nest-format/src/encoding: add an integer-stream codec module (delta+VarLong, optional
             block bit-pack) with a RESERVED v1 encoding id (4-255), applied first to the
             chunk_ids and chunks_original_spans sections; later, crates/nest-runtime/ann gets
             an on-mmap CSR adjacency index using the same codec with a branch-free unpack
             kernel in crates/nest-runtime/src/simd. Reimplement clean-room from the algorithm
             (GDS is GPL-3.0); determinism holds since all steps are pure functions of the
             sorted input.
compression: Directly on-mission. nest currently leans on zstd for non-embedding sections, but zstd is a
             general entropy coder that underperforms specialized integer codecs on dense
             monotonic ID/offset columns (chunk_ids, chunks_original_spans).
             Delta+VarLong+bitpacking is the standard way to push those columns toward 1-2
             bytes/value losslessly and decode at memcpy speed, advancing the
             compress-more-than-everyone goal while staying deterministic and mmap-friendly (no
             allocation, no entropy-decoder state). It also future-proofs the graph-search
             roadmap with a proven compact adjacency format.
perf:        Reported ~8.2 bytes/edge uncompressed vs ~1.4 bytes/edge after sort+delta+VarLong (~6x) on real
             graphs. Packed (bit-packed) variant: similar-or-better ratio than VarLong but
             strictly faster decompression due to branch-free unpack and better memory locality;
             ideal for traversal-heavy / tight inner loops. Block bit-packing is the same family
             as SIMD integer codecs (e.g. lnx-search/upack, FastPFor) so an AVX2/NEON unpack
             kernel in nest-runtime/simd is realistic. Decode requires zero allocation and no
             dictionary/window state, unlike zstd, so it is mmap-pure.
license:     GPL-3.0 (sources assemble into "OpenGDS"). LICENSE-INCOMPATIBLE with nest if nest is
             permissively licensed: do NOT copy code. The techniques (delta, VarLong/LEB128,
             block bit-packing, CSR) are decades-old public-domain algorithms, so reimplement
             from the algorithm, not from GDS source.
