================================================================================================
genome :: embedded-db (index)
embedded / datalog / temporal / kv / column storage engines (edit + real-time)
================================================================================================

one file per project in this folder. open the one you need.

[HIGH     ] replikativ__datahike.txt           A durable, immutable Datalog database that ports
                                               DataScript onto a content-addressed Hitchhiker
                                               tree (a fractal B+ tree with buffered write-logs)
                                               over the konserve pluggable KV store, giving
                                               append-only temporal facts, snapshot/time-travel,
                                               and structural-sharing dedup.
[HIGH     ] tonsky__datascript.txt             see above
[HIGH     ] xtdb__xtdb.txt                     XTDB v2 is a bitemporal SQL database whose
                                               primary index is a distributed LSM tree of
                                               immutable Apache Arrow files, sharded by a 2-bit
                                               (branching-factor-4) HAMT trie over entity-id,
                                               where each file publishes min/max + bloom-filter
                                               metadata and a single collapsed "recency" scalar
                                               so the query engine can prune whole files before
                                               touching their columnar buffers.
[HIGH     ] tidwall__buntdb.txt                An embeddable pure-Go in-memory key/value store
                                               that is ACID-durable via a single text
                                               append-only file (AOF) replayed on open, with
                                               copy-on-write B-tree indexes, pluggable Less
                                               comparators, GJSON path indexing, and an R-tree
                                               for spatial/k-NN queries.
[HIGH     ] tigerbeetle__tigerbeetle.txt       A statically-allocated, fully deterministic,
                                               single-file financial accounting database (Zig)
                                               whose entire on-disk state is a hash-chained tree
                                               of fixed 0.5 MiB grid blocks protected by
                                               out-of-band 128-bit AEGIS checksums, with an LSM
                                               "forest" over a WAL ring buffer and a 4-copy
                                               superblock root.
[HIGH     ] facebook__rocksdb.txt              An LSM-tree embedded key-value engine whose
                                               on-disk SST "block-based table" format combines
                                               prefix/delta-encoded sorted blocks with restart
                                               points, full/partitioned Bloom and Ribbon
                                               probabilistic filters, and trained-dictionary
                                               block compression to hit aggressive
                                               space-amplification targets.
[HIGH     ] duckdb__duckdb.txt                 An in-process columnar analytical database with a
                                               single-file, block-based storage engine that
                                               applies per-segment adaptive lightweight
                                               compression (RLE, bitpacking, FOR, delta,
                                               dictionary, FSST for strings, ALP for floats)
                                               chosen automatically by a sampling-based Analyze
                                               phase.
[HIGH     ] cruppstahl__upscaledb.txt          An embedded, page-based B+Tree
                                               key-value/analytical engine (single-file,
                                               multi-database, mmap'd) whose headline innovation
                                               is SIMD-accelerated integer-key compression
                                               inside B+Tree leaf KeyLists, plus analytical
                                               aggregates that run directly over compressed
                                               pages.
