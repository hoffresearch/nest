================================================================================================
genome :: model-runtime (index)
inference runtimes and tensor libraries for on-device embedding
================================================================================================

one file per project in this folder. open the one you need.

[MUST     ] ggerganov__ggml.txt                A dependency-free C/C++ tensor library for
                                               on-device inference whose real innovation is its
                                               block-quantization codec family (legacy Qn_0,
                                               K-quants with double-quantized super-block
                                               scales, and i-quants with shared codebook grids)
                                               packed into the mmap-aligned GGUF on-disk format
                                               and dequantized straight from disk by AVX2/NEON
                                               kernels.
[HIGH     ] microsoft__onnxruntime.txt         Cross-platform ML inference runtime whose CPU
                                               math library (MLAS) executes weight-only
                                               quantized matmuls via the MatMulNBits operator:
                                               block-wise sub-byte (int4/int8) weights with
                                               separate per-block scale/zero-point tensors,
                                               fused dequant-and-dot SIMD kernels (SQNBitGemm)
                                               dispatched per CPU feature level.
[HIGH     ] onnx__onnx.txt                     ONNX is a protobuf-defined interchange format for
                                               ML graphs whose TensorProto/external-data
                                               subsystem is a battle-tested spec for serializing
                                               quantized tensors (int4/int8/float8/MX
                                               microscaling) as raw, page-aligned, mmap-friendly
                                               byte blobs referenced by location/offset/length.
