================================================================================================
genome :: serialization-parsing (index)
zero-copy serialization, fast JSON/CSV parsing, mmap-friendly layouts
================================================================================================

one file per project in this folder. open the one you need.

[HIGH     ] simdjson__simdjson.txt             A branch-free two-stage SIMD JSON parser that
                                               classifies 64-byte chunks into
                                               structural-character bitmasks (stage 1) and
                                               materializes a flat 64-bit "tape" or lazily walks
                                               values via an On-Demand iterator (stage 2), with
                                               runtime CPU feature dispatch across
                                               AVX2/AVX-512/NEON/RISC-V.
[HIGH     ] serde-rs__serde.txt                A serialization framework that decouples N Rust
                                               data structures from M wire formats through a
                                               fixed 29-type abstract data model, with
                                               compile-time monomorphized derive codegen (no
                                               reflection, no intermediate Value tree) and
                                               lifetime-parameterized zero-copy deserialization
                                               (Deserialize&lt;'de&gt;) that borrows
                                               &amp;str/&amp;[u8] directly out of the input
                                               buffer.
[HIGH     ] google__flatbuffers.txt            A zero-copy cross-platform serialization library
                                               whose buffers are read in place (mmap-friendly)
                                               via a vtable indirection scheme, plus a
                                               schema-less sibling format (FlexBuffers) that
                                               auto-narrows every scalar/container to the
                                               smallest of 8/16/32/64-bit widths and pools
                                               strings/keys.
[HIGH     ] jzombie__rust-simd-r-drive.txt     A schema-less, append-only, single-file binary
                                               storage engine whose payloads are 64-byte-aligned
                                               for cache/SIMD efficiency, indexed by an
                                               in-memory xxh3_64 -> offset map, recoverable by a
                                               backward-linked metadata chain, and read fully
                                               zero-copy straight off mmap.
[MEDIUM   ] simd-lite__simd-json.txt           A Rust port of simdjson that parses JSON at
                                               multi-GB/s by splitting parsing into a SIMD
                                               stage1 (branchless structural-character indexing
                                               over 64-byte chunks) and a stage2 that walks that
                                               index to emit a flat u64 "tape", with zero-copy
                                               BorrowedValue referencing the input buffer.
[MEDIUM   ] cloudflare__mmap-sync.txt          A Rust single-writer/multi-reader IPC library
                                               that combines rkyv zero-copy archives with a
                                               tmpfs-backed mmap double-buffer and a wait-free
                                               RCU/Left-Right swap protocol so readers parse
                                               data in-place off the mmap with no locks and no
                                               copy.
[MEDIUM   ] p-ranav__csv2.txt                  A header-only C++17 CSV reader/writer that mmaps
                                               the whole file and lazily iterates cells via
                                               memchr-driven newline scans plus a branchy scalar
                                               quote state machine, hitting ~1 GB/s zero-copy
                                               without materializing the dataset.
