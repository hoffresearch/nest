================================================================================================
genome :: tokenizers (index)
tokenization (the front of every embed + a compression primitive)
================================================================================================

one file per project in this folder. open the one you need.

[HIGH     ] huggingface__tokenizers.txt        A Rust-core tokenization library
                                               (Python/Node/Ruby bindings) implementing BPE,
                                               WordPiece, Unigram and WordLevel behind a
                                               five-stage normalizer -> pre-tokenizer -> model
                                               -> post-processor -> decoder pipeline, with full
                                               original-span alignment tracking and a single
                                               self-describing tokenizer.json serialization.
[HIGH     ] google__sentencepiece.txt          Language-agnostic subword tokenizer that trains a
                                               unigram-LM (or BPE) vocabulary by EM + Viterbi
                                               over a lattice and ships the whole model (pieces,
                                               float scores, byte-fallback, NFKC normalizer FST)
                                               self-contained in one protobuf, decoded at
                                               runtime via a Darts double-array trie.
[HIGH     ] openai__tiktoken.txt               A fast Rust-core byte-level BPE (byte pair
                                               encoding) tokenizer whose vocabulary is a flat
                                               HashMap<Vec<u8>, Rank> mapping byte sequences to
                                               compact integer merge-priority ranks, driving a
                                               regex pre-split plus greedy lowest-rank merge
                                               loop that is reversible, lossless,
                                               language-agnostic, and deterministic.
[HIGH     ] OpenNMT__Tokenizer.txt             A fast C++ (with Python pyonmttok bindings)
                                               reversible tokenization library that combines
                                               Unicode-aware pre-segmentation with
                                               BPE/SentencePiece subword encoding, reversible
                                               joiner/spacer markup, and vocabulary-restricted
                                               recursive OOV splitting.
