                                               per-channel version numbers.
[HIGH     ] run-llama__llama_index.txt         A Python RAG/agent data framework whose core
                                               abstraction is the Node (a chunk with typed
                                               relationships, metadata, and a content/text hash
                                               id) wired into a swappable StorageContext
                                               (docstore + index_store + vector_store), with
                                               retrieval strategies including hierarchical
                                               multi-resolution chunking, auto-merging
                                               retrieval, and reciprocal-rank fusion hybrid
                                               search.

                                               on model2vec static embeddings

                                               bge-m3), simsimd SIMD cosine kernels, and an
                                               embedded qdrant-edge IVF_PQ index with a
                                               persistent on-disk workspace embedding cache.
[HIGH     ] infiniflow__ragflow.txt            RAGFlow is a layout-aware RAG engine (DeepDoc

                                               Infinity AI-native database, which serves a
                                               four-way hybrid search (dense vector via
                                               HNSW+LVQ, sparse vector, BM25 full-text, and
                                               ColBERT tensor/late-interaction) fused by RRF /
                                               weighted-sum / tensor reranking.

                                               profiles, and a temporally-aware knowledge graph
                                               behind one API, using Matryoshka (MRL)
                                               truncatable embeddings, AST-aware

                                               search with cross-encoder reranking under ~200ms.
[HIGH     ] neo4j__neo4j-graphrag-python.txt   A Python GraphRAG orchestration library that

                                               graph-traversal-Cypher, and text2cypher

[HIGH     ] FalkorDB__GraphRAG-SDK.txt         A Python GraphRAG orchestration SDK that does

                                               traversals as sparse linear algebra), then
                                               answers via multi-path retrieval (vector +
