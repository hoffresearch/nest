================================================================================================
genome :: ann-index (index)
approximate nearest neighbor indexes and libraries
================================================================================================

one file per project in this folder. open the one you need.

[MUST     ] facebookresearch__faiss.txt        FAISS is a C++/Python library of composable ANN
                                               indexes and vector codecs (PQ, additive
                                               quantizers, scalar quantization, IVF, HNSW) whose
                                               distinguishing feature is extreme lossy
                                               compression of vectors into short codes that
                                               remain searchable directly via SIMD lookup-table
                                               kernels, with a built-in two-stage
                                               approximate-then-rerank search contract.
[MUST     ] antgroup__vsag.txt                 VSAG is Ant Group's production C++ graph-ANN
                                               framework (HNSW/HGraph/IVF/SINDI) whose standout
                                               component is RaBitQ binary quantization, a
                                               randomized 1-bit-per-dimension codec with a
                                               provably unbiased distance estimator and a
                                               popcount-based SIMD hot path.
[MUST     ] zilliztech__knowhere.txt           Knowhere is the C++ vector-search core of Milvus,
                                               a unified index/config factory wrapping a
                                               Zilliz-optimized FAISS fork plus hnswlib and
                                               DiskANN, exposing HNSW/IVF/DiskANN/IVF_RABITQ
                                               indexes with SQ1-SQ8, PQ, and 1-bit RaBitQ
                                               quantization over a templated
                                               fp32/fp16/bf16/int8/bin1 operand type system with
                                               AVX512-VPOPCNTDQ and ARM-SVE SIMD kernels.
[MUST     ] criteo__autofaiss.txt              A Python wrapper over FAISS that auto-selects and
                                               tunes a KNN index (the faiss factory string +
                                               nlist + PQ subquantizers + nprobe/efSearch) from
                                               nb_vectors, dimension, a strict memory budget,
                                               and a query-latency target, via threshold
                                               heuristics plus binary search against measured
                                               recall.
[MUST     ] RyanCodrai__turbovec.txt           A Rust+PyO3 flat-scan ANN index implementing
                                               Google Research's TurboQuant: a data-oblivious
                                               (training-free) quantizer that random-rotates
                                               unit vectors so every coordinate follows a known
                                               Beta/Gaussian marginal, then applies precomputed
                                               Lloyd-Max 2/4-bit scalar quantization plus a
                                               per-vector length-renormalization scalar, scored
                                               directly in the compressed domain with
                                               FastScan-style nibble-LUT SIMD
                                               (AVX-512BW/AVX2/NEON).
[MUST     ] konjoai__vectro.txt                A Mojo-first (with a Rust `squish_quant`
                                               extension, MIT-licensed) embedding-compression +
                                               HNSW library offering 7 quantization codecs
                                               (INT8, NF4, PQ, Binary, RQ, learned autoencoder,
                                               kurtosis-routed AutoQuantize) wrapped in a
                                               self-describing VQZ container with optional
                                               ZSTD/zlib second-pass.
[HIGH     ] nmslib__hnswlib.txt                Header-only C++ implementation of HNSW
                                               (Hierarchical Navigable Small World) graphs with
                                               a flat byte-packed single-allocation graph
                                               layout, runtime-dispatched SIMD distance kernels
                                               (SSE/AVX/AVX512), and incremental
                                               insert/update/delete with deleted-slot reuse.
[HIGH     ] unum-cloud__USearch.txt            A single-C++11-header HNSW vector-search engine
                                               whose proximity graph and quantized vectors are
                                               packed into a contiguous, memory-mappable byte
                                               tape so an index is served zero-copy directly
                                               from disk, using compact uint40_t node IDs and
                                               transparent f16/i8/b1 downcasting.
[HIGH     ] hora-search__hora.txt              A pure-Rust, dependency-light (no BLAS) ANN
                                               library implementing HNSW, SSG,
                                               Random-Projection-Tree, and
                                               Product-Quantization/IVFPQ indexes over a generic
                                               ANNIndex<E,T> trait, with packed_simd distance
                                               kernels and serde+bincode dump/load persistence.
[HIGH     ] rust-cv__hnsw.txt                  A from-scratch, no_std-capable Rust HNSW
                                               (Malkov-Yashunin) index that is fully generic
                                               over the distance metric via the `space::Metric`
                                               trait, with const-generic fixed-width neighbor
                                               arrays and a first-class binary/Hamming path
                                               using XOR+popcnt over `Bits128..Bits4096` SIMD
                                               types and an amortized-O(1) `hamming-heap`.
[HIGH     ] djc__instant-distance.txt          A pure-Rust HNSW (Hierarchical Navigable Small
                                               Worlds, Malkov-Yashunin) approximate nearest
                                               neighbor index with fixed-arity neighbor arrays,
                                               generational visited tracking, the
                                               Malkov-Yashunin diversity pruning heuristic, and
                                               an optional serde serialization of the whole
                                               graph.
[HIGH     ] meilisearch__arroy.txt             A Rust ANN library that ports Spotify's Annoy
                                               (forest of random-projection / random-hyperplane
                                               trees) onto LMDB memory-mapped key-value storage,
                                               adding incremental insert/delete,
                                               RoaringBitmap-filtered search, and optional 1-bit
                                               binary quantization of stored vectors.
[HIGH     ] TusKANNy__kannolo.txt              A modular Rust (edition 2024, nightly
                                               portable-SIMD) HNSW + Product-Quantization ANN
                                               library whose real value for nest lives in its
                                               `vectorium` codec crate: a SIMD Stream-VByte
                                               sparse encoder with recursive-graph-bisection
                                               component reordering, an 8-bit PQ with SoA
                                               distance-table ADC, and cache-blocked batch-6
                                               distance kernels.
[MEDIUM   ] spotify__annoy.txt                 A C++/Python random-projection-forest ANN index
                                               whose entire forest lives in one contiguous,
                                               headerless, raw-float32 blob that is mmapped
                                               read-only and shared across processes with zero
                                               deserialization.
