SIMD, vectorization, portable intrinsics, fast string ops
================================================================================================

one file per project in this folder. open the one you need.

[HIGH     ] ARM-software__ComputeLibrary.txt   A production multi-ISA CPU/GPU kernel library
                                               (MIT) whose CPU core is `arm_gemm`: a bank of
                                               hand-tuned NEON/SVE/SVE2 micro-kernels selected
                                               at runtime by a CpuInfo feature-detection layer,
                                               including int8 GEMMLowp kernels that use
                                               SDOT/UDOT/I8MM dot-product instructions with
                                               int32 accumulation and an asymmetric (scale +
                                               zero-point) requantization output stage.
[HIGH     ] linebender__fearless_simd.txt      A Rust portable-SIMD library that encodes "this
                                               CPU feature is available" as a zero-sized
                                               type-level witness token (implementing the Simd
                                               trait), so write-once generic kernels
                                               monomorphize per instruction-set level
                                               (Fallback/Sse4_2/Avx2/Neon/WASM-simd128) and call
                                               intrinsics with no unsafe at the call site.
[HIGH     ] rust-lang__stdarch.txt             stdarch is the implementation home of Rust's
                                               `core::arch` / `std::arch` vendor intrinsics plus
                                               `std_detect` runtime CPU feature detection,
                                               organized as one
                                               `#[target_feature(enable=...)]`-gated intrinsic
                                               per machine instruction, with detection cached
                                               lock-free in an atomic bitset and verified by an
                                               `assert_instr` macro that disassembles the
                                               compiled shim to confirm the expected instruction
                                               was emitted.
[HIGH     ] BurntSushi__memchr.txt             A Rust crate providing CPU-feature-dispatched
                                               SIMD byte-search (memchr/2/3) and substring
                                               search (memmem) built on a write-once `Vector`
                                               trait abstraction, a frequency-ranked "packed
                                               pair" rare-byte prefilter, the Two-Way
                                               string-matching algorithm as a linear-time
                                               fallback, and a SWAR (SIMD-within-a-register)
                                               scalar path.
[HIGH     ] ashvardanian__StringZilla.txt      A portable C/C++ string library exposing
                                               CPU-feature-dispatched SIMD microkernels (NEON,
                                               AVX2, AVX-512, SVE, SWAR fallback, CUDA) for
                                               substring search, AES-NI hashing,
                                               Rabin-rolling-hash MinHash sketches,
                                               Levenshtein/Needleman-Wunsch alignment, argsort,
                                               and lookup-table byte transforms.
[MEDIUM   ] AdamNiederer__faster.txt           A Rust "SIMD for humans" library that exposes
                                               vectorized computation as iterator combinators
                                               (simd_iter / simd_map / simd_reduce /
                                               scalar_collect) over width-agnostic vector types
                                               (f32s, i8s, etc.), compiling each closure body
                                               down to 100% native SIMD via thin intrinsic
                                               wrappers plus scalar polyfills for missing
                                               instructions.
[MEDIUM   ] github.com__google__highway.txt    A C++ portable-SIMD library exposing a single
                                               width-agnostic ops API
                                               (Add/Mul/MulAdd/Load/Compress/Gather/Mask) that
                                               compiles each translation unit once per
                                               instruction set
                                               (SSE4/AVX2/AVX-512/NEON/SVE/RVV/WASM) and selects
                                               the best kernel at runtime via a function-pointer
                                               table, plus contrib kernels for vectorized
                                               quicksort (vqsort), math, and reductions.
[MEDIUM   ] intel__x86-simd-sort.txt           A C++ header library of SIMD (AVX-512/AVX2)
                                               sorting primitives - quicksort, quickselect,
                                               partialsort, argsort/argselect, and key-value
                                               sort for 16/32/64-bit ints and floats - built as
                                               a hybrid of vectorized quicksort partitioning
                                               plus branch-free bitonic sorting networks for
                                               small partitions.
[MEDIUM   ] simdutf__simdutf.txt               A dual-licensed (MIT/Apache-2.0) C++ library for

                                               that hits billions of chars/sec via per-arch
                                               kernels
                                               (SSE2/AVX2/AVX-512-VBMI2/NEON/SVE/RVV/POWER)
                                               selected by runtime CPU dispatch.
[LOW      ] Maratyszcza__FXdiv.txt             A ~1-file MIT C99/C++ header that replaces

                                               invariant integers via multiplication"
                                               magic-number scheme, with portable mulhi backends
                                               per platform.

                                               -- native passthrough, then cross-ISA emulation,

                                               scalar fallback -- exposing the FULL native API
