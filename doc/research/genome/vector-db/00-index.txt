================================================================================================
genome :: vector-db (index)
vector databases and sqlite vector/columnar extensions
================================================================================================

one file per project in this folder. open the one you need.

[MUST     ] qdrant__qdrant.txt                 A Rust vector database whose differentiating
                                               engine is a stack of rescore-backed quantization
                                               codecs (scalar int8, binary 1/1.5/2-bit, product,
                                               and the new data-oblivious TurboQuant) under an
                                               HNSW graph, where compressed vectors live hot and
                                               full-precision originals stay on disk purely for
                                               a two-stage rescore.
[MUST     ] milvus-io__milvus.txt              Distributed vector database whose single most
                                               transferable kernel is Knowhere/ScaNN's FastScan:
                                               4-bit product quantization scored by SIMD
                                               in-register lookup tables, combined with
                                               anisotropic quantization and a mandatory
                                               full-precision refine stage.
[MUST     ] chroma-core__chroma.txt            Chroma is a log-structured, Rust-core
                                               embedded/distributed vector DB whose index crate
                                               has converged on rotation-based binary/low-bit
                                               quantization (RaBitQ 1-bit/4-bit and TurboQuant
                                               3-bit) over a SPANN inverted index, with an
                                               Arrow-RecordBatch blockfile storage layer and
                                               HNSW centroid routing.
[MUST     ] weaviate__weaviate.txt             Go-based vector database whose flagship
                                               compression is 8-bit Rotational Quantization
                                               (RQ): a RaBitQ-inspired scheme that applies a
                                               fast pseudorandom Walsh-Hadamard rotation to each
                                               vector so per-vector min/max scalar quantization
                                               to int8 becomes near-lossless, then guarantees
                                               recall via a mandatory full-precision rescore
                                               stage on HNSW candidates.
[MUST     ] supervc-stack__VectorChord.txt     A PostgreSQL extension (vchordrq) that indexes
                                               vectors as IVF posting lists where each vector is
                                               stored as a tiny RaBitQ-quantized bit-code,
                                               scanning compressed codes with binary popcount
                                               arithmetic and deferring full-precision math to
                                               an adaptive rerank stage.
[MUST     ] sqliteai__sqlite-vector.txt        A pure-C SQLite extension that does ANN over
                                               plain BLOB columns with zero index build, pairing
                                               a runtime-dispatched SIMD distance table
                                               (SSE2/AVX2/NEON/RVV) with TurboQuant:
                                               rotation-based data-oblivious 2/3/4-bit scalar
                                               quantization scored via SIMD nibble lookup tables
                                               without vector reconstruction.
[MUST     ] asg017__sqlite-vec.txt             A pure-C, zero-dependency SQLite extension (vec0
                                               virtual table) that stores float32/int8/bit
                                               vectors in chunked shadow-table BLOBs and runs
                                               brute-force SIMD KNN with metadata/partition
                                               filtering, optionally using 1-bit binary
                                               quantization plus a
                                               coarse-search-then-float-rescore pattern.
[HIGH     ] lancedb__lancedb.txt               LanceDB is a disk-based, zero-copy embedded
                                               vector database built on the Lance columnar file
                                               format, which uses adaptive per-buffer
                                               structural+compressive encodings
                                               (miniblock/fullzip, FSST, bit-packing, RLE,
                                               byte-stream-split) and decomposes every vector
                                               index into the three composable parts IVF
                                               clustering + sub-index (FLAT/HNSW) + quantization
                                               (PQ/SQ/RaBitQ) with residual encoding and an
                                               uncompressed-vector refine rerank.
[HIGH     ] pgvector__pgvector.txt             A PostgreSQL extension implementing exact +
                                               approximate (HNSW, IVFFlat) vector search over
                                               four vector types (float32 vector, float16
                                               halfvec, binary bit, sparsevec) with
                                               scalar/binary quantization codecs, distance
                                               operators for
                                               L2/cosine/inner-product/L1/Hamming/Jaccard, and a
                                               binary-quantize-coarse-filter-then-exact-rerank
                                               retrieval pattern.
[HIGH     ] sqliteai__sqlite-columnar.txt      A self-contained SQLite loadable extension that
                                               adds column-oriented virtual tables backed by
                                               shadow tables, fixed 65,536-row chunks, and
                                               per-chunk min/max zone maps so analytical
                                               scans/aggregations skip non-matching rowid ranges
                                               and aggregate natively in C, hitting up to
                                               130,000x speedups without patching SQLite's
                                               pager/btree/VDBE.
[REFERENCE] asg017__sqlite-vss.txt             A SQLite extension (vss0 virtual table + vector0
                                               codec module) that bolts Facebook Faiss onto
                                               SQLite by serializing an entire Faiss index into
                                               a single BLOB inside an fts5-style shadow table,
                                               with index type chosen declaratively via Faiss
                                               factory strings.
