# NOW  (4 cards)
################################################################################################

[ ] Land SECTION_EMBEDDINGS_FP=0x09 rerank source + make score_subset use it   (CRITICAL)
    The gate for all sub-int8 work. score_subset (search.rs:84-121) reranks against the SAME
    lossy stored dtype today, so below int8 'real cosine' silently becomes 'real cosine at
    stored precision'. Reserve an optional f16/f32 rerank-source section (excluded from
    content_hash) and rerank survivors against it when present. Additive, no version bump.
    refs: crates/nest-runtime/src/search.rs, crates/nest-format/src/sections/contract.rs,
          gaoj0017/RaBitQ

[ ] Fix materialize-to-f32 RAM leak in the ANN distance path   (CRITICAL)
    materialize_f32_vectors (materialize.rs:32-41) expands EVERY dtype to n*dim*4 f32 whenever
    HNSW is attached (mmap_file.rs:113), so int8/int4 halve disk but keep a dense f32 copy in
    RAM on exactly the tiny/hybrid presets that need it. Teach the ANN path to score packed int8
    blocks (or keep f16). Pure runtime fix, no format change.
    refs: crates/nest-runtime/src/materialize.rs, crates/nest-runtime/src/ann/mod.rs,
          microsoft/onnxruntime

[ ] Codec registry refactor + reserve encoding ids 4-9 / section ids 0x09-0x10   (HIGH)
    Turn decode_payload (encoding/mod.rs:44-55) into a visitor-style registry, one <=300-line
    module per encoding id; reserve the named constants in layout/mod.rs. Must be byte-identical
    on existing presets (golden/v01_compat tests). Unblocks every later codec.
    refs: crates/nest-format/src/encoding/mod.rs, crates/nest-format/src/layout/mod.rs,
          serde-rs/serde

[ ] Per-codec roundtrip+content_hash-equality test template + MTEB-style recall harness   (HIGH)
    Every new codec must pass decode==input AND content_hash-stable (mirror
    zstd_roundtrip_preserves_bytes). Extend benchmark with seeded nDCG/MRR/Recall@k vs exact f32
    baseline per preset + a byte-identical-build CI check. The safety net that lets later codecs
    push harder with proof.
    refs: crates/nest-format/src/encoding/mod.rs, crates/nest-cli/src/cmd/benchmark.rs,
          embeddings-benchmark/mteb

# NEXT  (6 cards)
################################################################################################

[ ] Shared intpack codec (delta+zigzag+per-128-block bitpack/FOR with O(1) select)   (HIGH)
    SECTION_ENCODING_INTPACK=4, the reusable primitive for HNSW/BM25/spans. Branch-free scalar
    decode, never panic on truncated input, O(1) select by bit-offset so spans[i]/neighbor[i]
    stay fetchable off mmap. Clean-room PFOR exceptions from the FastPFor format description
    (avoid GPL TurboPFor).
    refs: crates/nest-format/src/encoding/intpack.rs, lemire/FastPFor, cruppstahl/libfor

[ ] Re-encode HNSW neighbor ids + BM25 postings with intpack   (HIGH)
    Sort-per-list + delta+bitpack HNSW neighbor ids (flat uint40, bump HNSW_PAYLOAD_VERSION,
    identical id set => zero recall change). Delta-gap BM25 doc ids + bitpacked tf + 1-byte
    log-quantized doc_lengths (bump BM25_PAYLOAD_VERSION). Biggest free shrink of the
    tiny/hybrid index sections.
    refs: crates/nest-runtime/src/ann/codec.rs, crates/nest-runtime/src/bm25/codec.rs,
          apache/lucene

[ ] chunk_ids as 32 raw SHA-256 bytes + spans source_uri dedup + offset tables   (HIGH)
    Store 32 raw digest bytes not 71-byte ascii (~2.2x, reconstruct sha256:<hex> on decode,
    content_hash unchanged). Dedup repeated source_uri into a string pool + delta+varint span
    offsets. Add a u32 offset table so cite/materialize reach chunk N in O(1) instead of an O(n)
    scan.
    refs: crates/nest-format/src/sections/chunk_ids.rs,
          crates/nest-format/src/sections/spans.rs, google/flatbuffers

[ ] Trained shared zstd dictionary + FSST + zstd level/LDM knobs   (HIGH)
    SECTION_DICTIONARY=0x0A + SECTION_ENCODING_ZSTD_DICT=5 (ZDICT over sorted samples,
    deterministic) kills cross-chunk redundancy on many-short-similar PT-BR chunks. FSST (id 9)
    for O(1) single-chunk citation reopen. Replace hardcoded level-19 (zstd_codec.rs:10) with
    level/LDM params. Headline text ratio lever.
    refs: crates/nest-format/src/encoding/zstd_dict.rs, crates/nest-format/src/encoding/fsst.rs,
          facebook/rocksdb

[ ] Block-scaled + rotational int8 (scale_kind=1, no new id, no version bump)   (HIGH)
    One f16 scale per 32-dim block recovers per-vector-outlier loss at the same 4x size; seeded
    FWHT rotation before quantize pushes recall@10 toward ~0.99. The int8 scale_kind field
    already exists at int8.rs:18 and parse() rejects unknown kinds, so old readers stay safe.
    Pair with VNNI/dotprod for bit-determinism.
    refs: crates/nest-format/src/encoding/int8.rs, ggml-org/ggml, weaviate/recipes

[ ] Zero-copy PyBuffer query + maturin cp312-abi3 wheel   (MEDIUM)
    Replace query.extract::<Vec<f32>>() (nest_file.rs:23) with a PyBuffer<f32> borrow +
    Python::detach around the read-only mmap search; ship one cp312-abi3 wheel to PyPI. Stops
    the compression wins being paid back as per-search alloc+memcpy, and closes the install gap.
    refs: crates/nest-python/src/nest_file.rs, pyproject.toml, PyO3/pyo3

    SECTION_ENCODING_INT4=7 (~4.25bpw), split pack/unpack from kernel, fused SQNBitGemm-style
    kernel that never materializes f32 in RAM, DType::Int4 arm. Gate the preset on the

    refs: crates/nest-format/src/encoding/int4.rs, crates/nest-runtime/src/simd/int4.rs,

[ ] RaBitQ 1-bit codec + popcount kernel + nano preset   (MEDIUM)
    SECTION_ENCODING_RABITQ=8: seeded FHT rotation + sign bits + ~2 f32 correctors, AND+popcount
    candidate gen, then exact rerank against embeddings_fp -> real cosine. ~32x. Validate
    recall@10 on the PT-BR demo model before defaulting; keep int8/RQ the safe default and never
    ship without bm25 backstop.
    refs: crates/nest-format/src/encoding/rabitq.rs, crates/nest-runtime/src/simd/popcount.rs,
          VectorDB-NTU/RaBitQ-Library

[ ] Content-hash dedup before zstd + chunk_scalars pre-filter   (MEDIUM)
    Build-time dedup of identical chunks (SECTION_DEDUP_MAP=0x0B, unique pool + u32 back-ref) on
    DECOMPRESSED bytes, zstd after - encode the order as a code-level invariant + test.
    Re-expand to identical bytes so content_hash/citations invariant. Add
    SECTION_CHUNK_SCALARS=0x0D columnar pre-filter, opt-in.
    refs: crates/nest-format/src/encoding/dedup.rs,
          crates/nest-format/src/sections/chunk_scalars.rs, NixOS/nix

[ ] Matryoshka prefix truncation + micro/nano preset ladder   (MEDIUM)
    Build-time truncate+L2-renorm to mrl_dim, two-pass coarse(prefix)->exact(full) search,
    multiplicative with quantization. Ship micro (block/RQ-int8) and nano (int4/rabitq) presets

    refs: crates/nest-python/src/build_fn.rs, QwenLM/Qwen3-Embedding

[ ] CSR graph_adjacency section + search-graph subcommand   (LOW)
    SECTION_GRAPH_ADJACENCY=0x0C (chunk-to-chunk edges, reusing intpack), bounded-BFS seeded

    refs: crates/nest-runtime/src/graph/, crates/nest-cli/src/cmd/search_graph.rs,

[ ] Byte-level subword tokenizer for CJK/Thai BM25 + text front-end   (LOW)

    refs: crates/nest-runtime/src/bm25/tokenize.rs, google/sentencepiece, openai/tiktoken

[ ] Append-only edit journal + deterministic compact()   (LOW)
    SECTION_EDIT_JOURNAL=0x0F overlaid in memory at open (frozen bytes immutable) + compact()

    refs: crates/nest-runtime/src/journal.rs, crates/nest-cli/src/cmd/compact.rs, tidwall/buntdb

[ ] BLAKE3 Merkle-root content_hash (the one true v2)   (LOW)
    Make content_hash a Merkle root over per-section/per-chunk hashes for O(touched-bytes)
    partial verification + single-chunk citation proof + corpus-level subtree dedup. Changes the
    meaning of an existing field, so it MUST be NEST_FORMAT_VERSION=2 with v1 readers retained.
    Ship SECTION_MERKLE_INDEX + a new additive blake3 algorithm-id FIRST; bump only on measured
    demand.
    refs: crates/nest-format/src/hashing.rs, BLAKE3-team/BLAKE3, tigerbeetle/tigerbeetle

[ ] Structured tape (json/yaml/parquet) + per-column codec cascade   (LOW)
    Fixed-stride u64 tape + length-prefixed value blob (simdjson-style) + min-width offsets +
    key-interning, sub-document citable. Per-column DuckDB-style Analyze-and-pick cascade.
    Portable parity scan (no PCLMULQDQ) for cross-CPU determinism. The
    compress-AND-serve-structured-data lever.
    refs: crates/nest-format/src/encoding/structure.rs, simdjson/simdjson, duckdb/duckdb

[ ] Sovereign in-house FSE/tANS entropy floor over delta-coded postings   (LOW)
    In-house FSE/tANS + Huff0 (new reserved encoding ids) over delta-coded BM25 postings, HNSW
    adjacency, term dictionaries - a deterministic table-build entropy floor below generic zstd
    on skewed residuals; libdeflate-style two-level decode table for mmap-friendly decode.
    Larger surface, lowest priority.
    refs: crates/nest-format/src/encoding/fse.rs, Cyan4973/FiniteStateEntropy,
          ebiggers/libdeflate

[ ] PDF/audio/video ingestion + copy-without-recode media payloads   (LOW)
    Canonicalize PDF to deterministic text before chunking (then it IS the text path), store
    media verbatim by content_hash with a CDC chunk index (never lossy-re-encode inside the
    container), CLIP-style L2-normalized media embeddings ride the same quantization ladder.
    FastCDC content-defined chunking for edit-local rechunking.
    refs: crates/nest-python/src/build_fn.rs, activeloopai/deeplake, ipfs/kubo

[ ] Algorithm-4 diversity neighbor selection + generational visited set   (LOW)
    Replace the _simple top-m HNSW neighbor selection (ann/mod.rs:33 flags this as planned) with
    Malkov-Yashunin Algorithm-4 so recall rises at fixed M, letting tiny/nano presets LOWER M
    and shrink the index. Route traversal through the SIMD dispatcher and swap the per-query
    HashSet for a generational buffer.
    refs: crates/nest-runtime/src/ann/select_neighbors.rs, djc/instant-distance, nmslib/hnswlib
