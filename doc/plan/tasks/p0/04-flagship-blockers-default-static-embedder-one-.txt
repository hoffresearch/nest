--- STEPS (check each) ---
[x] DEFAULT static embedder beside forge: tiny, fully offline, deterministic, NO network on
    first use; support a brought sentence-transformers model whose fingerprint is recorded
    -> python/forge/embed_default.py: a model2vec-STYLE static embedder, stdlib-only (no torch,
       no download, no socket). tokenize (unicode-alnum-lower) -> fixed pseudo-random per-token
       vectors from a seeded sha256 stream (no stored table needed) -> l2-normalized mean ->
       f32-stable so a cache-backed rebuild is byte-identical. it is a quality FLOOR (cosine
       captures lexical overlap); the brought-model path stays the quality ceiling, and which
       embedder produced a corpus is recorded by its model_hash. callable as builder.Pipeline's
       `embedder` (reads .canonical_text or raw strings). DESIGN NOTE: the plan said "vendor a
       static model2vec/potion table"; a downloaded distilled table is a drop-in QUALITY upgrade
       with the same interface + fingerprint, but the BLOCKER (offline, deterministic, no-network,
       tiny) is fully met without any vendored multi-MB file or network access.
[x] ONE concrete, vendored, license-clean demo doc folder NOW
    -> python/forge/demo_corpus/: original prose (cc0, public-domain) about nest itself (what a
       .nest is, what forge does, citations, offline sovereignty) + a README stating the cc0
       license. zero third-party/academic data, so it redistributes freely with the project.
[x] record embedder fingerprint in provenance so byte-identical builds are provable
    -> StaticEmbedder.model_hash() = "sha256:" + sha256(canonical-json(config)), the SAME
       convention as model_fingerprint.fingerprint_to_model_hash, so the manifest model_hash gate
       treats it uniformly. the existing builder.Pipeline/nest.build path records model_hash into
       the manifest; the forge adapter wires it when it builds a corpus (forge-0b/#09).
       model_fingerprint.py was left UNTOUCHED (the static embedder self-fingerprints with the
       same idiom; no change to the ST file fingerprinter was needed).
